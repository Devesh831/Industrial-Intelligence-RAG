# Public demo API

Run from the repository root: `pip install -r backend/requirements.txt` then `uvicorn backend.app:app --reload --port 7860`. The first start downloads MiniLM and FLAN-T5-small. Set `FRONTEND_ORIGINS=http://localhost:3000` for local CORS. `GET /analytics` returns approved aggregate results; `POST /ask` accepts `{"question":"..."}` and indexes only generated fictional PDFs. `/health` reports API availability.

For Hugging Face Spaces, create a **Docker** Space and push this repository as its contents. The root `Dockerfile` is the Space entry point; the YAML front matter at the top of the root README sets `sdk: docker` and `app_port: 7860`. Set `FRONTEND_ORIGINS` to the exact Vercel origin. Wait for `/health` to return `status: ready`, `models_ready: true` and `index_ready: true` before testing `/analytics` or `/ask`. Free CPU startup can take several minutes; ephemeral `/tmp` storage causes reindexing on restart. For production, use persistent storage and health monitoring. No secret keys are needed for the public sample.
